## Strict temporal and evidence rules

Supersession requires the same provider and TMDB identity, accepted frozen route and identity, explicit replayed lifecycle evidence for a later season, a strictly newer valid non-future announcement, first-party HTTPS sources, and independent reconstruction matching all seven persisted fields. A newer publication alone is insufficient. No global status precedence was invented; same-season status transitions remain conservative/inconclusive.

Equivalence requires both historical and current valid frozen replays, the same identity/provider/status/season and equal release fields. A second valid first-party lifecycle announcement may differ in URL/publication date. Canonical equivalence requires all six non-URL fields equal. Safe audit-only normalization handles host case, trailing slash, unreserved percent encoding and known tracking parameters; semantic query parameters remain. HTTP-to-HTTPS upgrades and unproven redirect equivalence are not accepted. Same canonical article with changed announcementDate is conflicting, including a later-season claim. Production reconstruction still compares its original seven fields exactly.

Trailers, teasers, casting, ratings, interviews, recaps, production-start news without lifecycle claims, wrong identities, unsupported seasons, third-party sources, regional date-only claims and ambiguous title/season evidence cannot qualify. No regional date is promoted to global truth. Missing/invalid proof and network uncertainty cannot increase coverage. Explicit source/provider/network/local unavailability remains INCONCLUSIVE even after generic discovery; it cannot enter real-parser-failure ROI.
